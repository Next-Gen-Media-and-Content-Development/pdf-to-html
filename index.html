Spec compliance

Step-7 QA gate

Every conversion is measured against the standard before download.

  • ✓
    Folder of separate files
    No single-file bundle, no base64 assets in HTML
  • ✓
    All images WebP, lazy loaded
    Cover eager; all others loading="lazy" decoding="async"
  • ✓
    KaTeX maths with data-latex
    Auto-render, offline-capable, copy yields LaTeX
  • ✓
    Real selectable text throughout
    user-select:text; no custom ::selection colour
  • ✓
    Body prose justified + hyphenated
    text-align:justify; hyphens:auto on p elements only
  • ✓
    JS deferred; one external CSS
    No inline style/script blobs in index.html
  • ✓
    _headers cache rules included
    CSS/JS/img far-future cache; HTML must-revalidate
  • ✓
    Mobile-first full viewport width
    Page container = page width; no pinch-zoom needed
  • ✓
    Single continuous column
    No page-break dividers; one scrollable document
  • ✓
    Tables scroll in-box
    overflow-x:auto on .table-wrap; page never widens
  • ✓
    Chrome/artifacts stripped
    Running headers, page numbers, sluglines excluded
  • ✓
    QA report in ZIP
    data/qa-report.json with all spec checks documented
